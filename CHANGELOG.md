# CHANGELOG
Here's where all of the changes made to both the repository AND the code will be stored. In order to identify them, the next format will be used when making a pull request:

{origin}-[folder/file]-{type}: txt
* origin - R (Repository) or C (Code)
* folder/file - Specifies the exact location of the modified file (if the file is in the main repository file (Webpage/), this parameter will be ignored
* type - Wheter it's an upload, fix, removal, upgrade, replacement (moved to another folder), etc. All will be written fully (no abreviations) to avoid confusion
* txt - Text specifying what the change was
* Example - R-Folder/File-Fix: Fixed documentation

For logging on this file, the next format will be used:

--> {date} {time}

txt

* {date} - Date the changes were made
* {time} - Exact time when the pull request was sent
* txt - Description of changes made (in a list)
